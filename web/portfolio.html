RxDx knowledge assistant

The original assignment: “First has to be RAG based. Develop a QnA bot for RxDx for now.” The result retrieves clinic evidence before answering, with sources readers can inspect.

Read the case studyTry the live bot

A hybrid BM25 + embedding pipeline searches 427 chunks built from 343 public records. A separate navigator uses exact doctor filters for branch, day and language.

Launch evidence: 88 tests passed; retrieval hit@8 of 100% and MRR of 0.889 on 30 curated questions. These measure retrieval, not general answer accuracy.
